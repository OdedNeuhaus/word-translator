# word-translator
A Chrome extension to translate words to Hebrew easily.

##### How to activate?
1. Clone the repo to your workspace.
2. Go to `chrome://extensions/`,
3. Choose 'Load unpack'.
4. Choose the 'word-translator' folder.

##### How to use?
Just mark a word that you want to translate and click 'Translate to Hebrew'.
